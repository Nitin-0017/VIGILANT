# Storage

## Uploads

Files larger than 10 MB are rejected before they reach the server.

## Retention

Deleted files stay in the bin for two weeks and are then erased for good.

## Backups

A copy of all customer files is made every night and kept in a second region.

## Thumbnails

Small previews of images are generated when a file is first viewed.

## Downloading

`storage.fetch` returns a file's bytes.
