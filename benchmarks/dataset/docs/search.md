# Search

## Query syntax

Put a phrase in quotes to find those exact words, and use a minus sign to exclude a word.

## Ranking

Products whose title contains the search words appear above those with matches only in the description.

## Indexing

New products become findable about a minute after they are published.

## Result pages

The catalogue shows twenty products on each screen.

## Suggestions

`suggest_terms` offers completions as a customer types.
