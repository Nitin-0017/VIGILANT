# Users

## Creating accounts

Call `create_user` with a name. New accounts get the viewer role unless another role is passed.

## Deleting accounts

After `delete_user`, an account can be restored by support within 30 days.

## Roles and permissions

Admins can manage every account. Editors can change content, and viewers can only read it.

## Profile pictures

Profile pictures are cropped to a square and stored as PNG files.

## Exporting accounts

`export_users` writes accounts to a CSV file for compliance reviews.
